# Autonomous Runbook design system

The product should feel calm, inspectable, and operational—not like a gamified job board.

- Archivo carries product language; IBM Plex Mono carries run state and evidence.
- Off-white is the default canvas. Navy establishes trust, cobalt shows action, green confirms verified work, and coral is reserved for pauses.
- Use one clear primary action per section. Prefer plain sentences over slogans.
- Show evidence as receipts, thresholds, and run states. Never present illustrative numbers as real customer results.
- Motion is subtle and respects reduced-motion preferences.
