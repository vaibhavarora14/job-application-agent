# Site contributor guidance

Preserve the Autonomous Runbook design in `DESIGN.md`. The open-source agent remains the product foundation, but the public conversion journey should focus on cloud access (a hosted agent) without a competing local-install CTA. Do not invent customer counts, placement claims, or application success rates. Keep founding payment copy honest: Cloud access is COMING SOON; $49 reserves founding pricing for cloud access when it launches — not instant access — and we email a reservation confirmation after verified payment (no instant self-serve dashboard claim unless that path ships). Do not use OPEN or READY on cloud access while it is still coming soon. One product story only — do not present Hosted continuity and Cloud access as peer lanes or dual COMING SOON chips. “Smarter agent on cloud” is quiet supporting body only, never a badge or SKU. Do not promise launch dates, activation deadlines, or automatic refunds in public offer, FAQ, terms, privacy, or return copy.
